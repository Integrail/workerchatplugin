🎤 Everworker Voice Plugin

This is a simple example demonstrating how to integrate the Everworker Voice Plugin into your website.

Configuration

How it works

Once initialized, you'll see a floating button in the bottom-right corner of the page. Click it to open the chat interface where you can:

  • Type messages to interact with your AI agent
  • Use voice input for hands-free communication
  • See real-time transcriptions of your speech
  • Receive both text and voice responses

Features

  • ✅ Real-time WebRTC voice streaming
  • ✅ DDP connection with fallback to REST API
  • ✅ Shadow DOM for style isolation
  • ✅ Persistent chat history
  • ✅ Auto-reconnection
  • ✅ Dark mode support
